# AmorArtificial.com — Premium Domain Landing Page

High-conversion, single-page Next.js 15 application for the premium domain **AmorArtificial.com** (available for acquisition — not a live business).

## Tech Stack

- Next.js 15+ (App Router)
- TypeScript (strict)
- Tailwind CSS v4
- Framer Motion
- Lucide React
- Vercel / Cloudflare compatible

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npm run build
```

Deploy to Vercel or Cloudflare Pages with the standard Next.js adapter.

## Environment

Optional:

```env
NEXT_PUBLIC_SITE_URL=https://amorartificial.com
```
